# Agent report: gavindi/Aula_L99_Linux (condensed key facts)

- Dongle 05AC:024F: vendor channel on interface 3, 32-byte INTERRUPT reports (wired: 64-byte feature reports). Screen EEEF:268A CDC-ACM, bulk 0x03 OUT / 0x82 IN, raw mode, baud ignored.
- Q2: documentation/Firmware/ NOT in the clone (gitignored Windows/). Screen updater = Qt5/MinGW, QSerialPort only, two phases: HFD_Code_V2.x.bin ("Fail to Connect a mcu device") then UartTFT-II_Flash.bin ("Fail to Connect a 268x device"). CRC only, no signing seen. Wire framing NOT extracted (code span 0x406fce–0x409cf7 unread). Upgrade mode: FN + X, 0, 6. Reset package = 194 MB Enigma-Protector exe, not unpacked. Chip = LT168B (schematic), proprietary RISC core. Verdict: no Mac path to apply reset package today; Windows (or VM w/ USB passthrough) only. Wine can't see CDC port.
- Q3: no readback/dump command. Commit reply carries 4-byte checksum of region written (could verify slot matches a known file — untested).
- Q7: static image 11-byte header (u32 LE size, u16 w, u16 h, 0x00, CRC16/MODBUS LE of pixels) + RGB565 LE. Vendor truncates, no dither. Reject >320x480 (overflows next slot).
- GIF rules (empirical): all frames same delay (else fallback animation); <=255 frames (vendor 200); 528-byte prefix tolerates <=8 nonzero padding bytes; adjacent runs must not share palette index; validator semantics only partially known. Failed GIF still ACKed → panel plays cached fallback; re-upload good blob fixes (sometimes 2 tries).
- Colour: vendor gives own palette slot only if max(R,G,B) is 0 or 255; else dithers onto ramp R/B {0,6,12,19,25,31}, G {0,10,21,32,42,53,63} (252 colours). Unknown whether arbitrary RGB565 palette entries display (tested only up to 11 ramp-legal slots). Repo uses Floyd–Steinberg onto that ramp — works on hardware.
- Q8 frame (agent's own CRC check reconciles repo's lookup table): 5A A5 | 00 | BE16(N+7) | CMD (0x64 write / 0x66 commit) | BE32 addr | payload[N] | CRC16/MODBUS LE over CMD..payload. (= AxiraDev's u24 length.) 2048-B writes; commit (0x66, addr=region start, payload BE32 byte count) after each 128 KiB and last chunk. Write reply 19 B with "OK"; commit reply 21 B w/ 4-byte checksum. 0.5 s reply timeout, stop on NAK. No refresh command — panel may need restart/page change.
- Salamor 12 34 56 78 JPEG protocol = different display 87ad:70db (agrees with AxiraDev finding).
- Firmware version: dongle session-init reply byte 11 = build byte (0x29 on L99). None for cable/screen.
- GIF blob at 0x04240000: TOC N×20 B LE: [0:4] frame offset, [4:8] total size, [8:10] w, [10:12] h, [12]=3, [13] frame count, [14:16]=0, [16:18] delay (centiseconds?), [18:20] CRC16/MODBUS over all frames. Frame: 528-byte prefix "LT" w h 01 03, [8:12] frame size, [12:14] content len mod 65536, [14:16] mode 0x0100 RLE / 0x0002 raw, [16..] palette RGB565 LE first-appearance <=256; content RLE (len-1, idx) pairs, runs split at 256; raw mode 1 B/px when RLE >0xFFFF. Vendor format max ~13.2 MB; CLI refuses bigger. ~61.75 MB slot estimate is inference only.
- Flash slot table (stride 0x60000): 0x04060000 ?, 0x040C0000 ?, 0x04120000 ?, 0x04180000 background, 0x041E0000 photo, 0x04240000 GIF (open-ended). 128 MB NAND inferred.
- HID cable: 04 <op>, byte 8 = block count; begin 0x18, cmd, blocks, commit 0x02, end 0xF0; ack byte3=01; last block AA 55 at 62–63.
